# Проверка выделенного проекта

Проверено при отделении 27 октября 2026 года:

- 37 автоматических тестов: сохранение и история всех 13 тестов, порядок вопросов, заполнение каталога без перезаписи правок, регистрация, профиль, удаление профиля, восстановление пароля, разделение cookie двух проектов, заявки и права доступа, границы алертов и смена роли при старом токене.
- Ruff: F821/F401 без ошибок; исходники отформатированы.
- Приложение импортируется самостоятельно, OpenAPI содержит 47 путей.
- В новой предметной схеме 12 таблиц.
- `docker compose config --quiet` прошёл.
- SQL миграции `compas_0001` и отката с неё до base собирается в PostgreSQL-диалекте Alembic.

Автотесты работают на SQLite в памяти. Адаптер массивов существует только в тестах. Проверки чтения/записи используют реальные SQLAlchemy-модели и репозитории.

При первоначальном отделении Docker daemon был выключен. При последующей подготовке локального запуска выполнено:

- создано самостоятельное окружение Python 3.12.10, установлены runtime- и test-зависимости; `pip check` не выявил конфликтов;
- запущен собственный PostgreSQL 18, контейнер healthy;
- начальная миграция применена на PostgreSQL; `alembic check` не обнаружил расхождений моделей и БД;
- заполнен каталог; API возвращает все 13 тестов;
- приложение запущено на 127.0.0.1:8001; readiness=ready, Swagger HTTP 200;
- 37 автотестов повторно прошли в собственном окружении Compas.

Сборка Docker-образа приложения, нагрузочный прогон, отправка реального письма и восстановление настоящего дампа пока **не выполнены**. API при этой проверке запущен локальным Python, в Docker работает только PostgreSQL.

После добавления Яндекс OAuth:

- 54 автоматических теста прошли, включая state, PKCE, ошибки провайдера, создание и привязку аккаунтов, сохранение роли;
- применена миграция `compas_0002` с необязательным уникальным `users.yandex_id`; `alembic check` подтвердил соответствие моделей БД;
- API перезапущен с четырьмя ручками `/yandex/*`;
- живой вход через Яндекс пока не проверен. Владелец создал отдельное OAuth-приложение Compas; его ключи подключены через `.env` вместо ранее переиспользованных ключей «Одеяло». Построение OAuth-перехода с новым приложением проверено, API перезапущен. Сетевые ответы Яндекса в автотестах подменяются.

Исходная база и сервер «Одеяло» не изменялись. Реальные аккаунты и история не переносились. Проект не пушился и на сервере не развёртывался.
